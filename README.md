# Interactive Radar Systems & DSP Simulation Workbench

![Version](https://img.shields.io/badge/Version-2.0.0-06b6d4)
![Architecture](https://img.shields.io/badge/Architecture-Vanilla_JS_SPA-10b981)

![License](https://img.shields.io/badge/License-MIT-f59e0b)

A desktop-class, real-time interactive scientific simulation workbench for **Radar Systems Engineering and Digital Signal Processing (DSP)**. Designed as a zero-dependency Single-Page Application (SPA) with a strict **Fixed-Viewport (No-Scroll) Laboratory Interface**, this platform enables engineers, researchers, and graduate students to analyze and compare **Linear Frequency Modulation (Chirp)**, **Pulsed Time-of-Flight (ToF) Radar**, **Unmodulated Continuous-Wave (CW) Doppler Radar**, and **77 GHz Frequency-Modulated Continuous-Wave (FMCW) Radar**.
